# TrickTime — сайт Minecraft-сервера

Готовый адаптивный сайт на HTML/CSS/JavaScript. Ничего не стоит и не требует сборки.

## Как открыть
Открой `index.html` в браузере.

## Как получить бесплатный URL через GitHub Pages
1. Создай аккаунт на https://github.com, если его ещё нет.
2. Создай публичный репозиторий с названием `tricktime`.
3. Загрузи `index.html` и этот README в репозиторий.
4. Открой **Settings → Pages**.
5. В разделе Build and deployment выбери **Deploy from a branch**, ветку `main`, папку `/ (root)` и нажми Save.
6. После публикации сайт будет доступен по адресу вида `https://ТВОЙ-ЛОГИН.github.io/tricktime/`.

Это бесплатный адрес. Более короткий адрес вроде `tricktime.net` обычно требует покупки домена. Можно также попробовать бесплатный поддомен хостинга, например на Netlify.

## Важно настроить перед публикацией
- В `index.html` найди `const SERVER_IP = "PLAY.TRICKTIME.ME";` и замени на настоящий IP своего Minecraft-сервера.
- Формы сейчас работают **только в демонстрационном режиме**: они проверяют заполнение, но никуда не отправляют заявки. Чтобы получать обращения, подключи сервис обработки форм (например, Formspree) или собственный backend и измени обработчик `requestForm` в конце файла.
- Укажи реальные ссылки на Discord/соцсети и актуальную информацию о донате, если они нужны.
- Проверь правила обработки персональных данных перед сбором контактов игроков.
