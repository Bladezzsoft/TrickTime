# TrickTime — сайт Minecraft-сервера

IP сервера: `tricktime.mc-join.me`

## Бесплатная публикация на GitHub Pages
1. Загрузите `index.html` в корень публичного репозитория GitHub.
2. Откройте **Settings → Pages**.
3. В `Build and deployment` выберите `Deploy from a branch`, ветку `main`, папку `/ (root)`, затем `Save`.
4. После публикации откройте URL, показанный в разделе Pages.

## Важно
Формы обращений пока работают в демонстрационном режиме и не отправляют данные администрации. Для реального получения заявок подключите обработчик форм или backend.
